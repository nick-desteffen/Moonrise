## Rules

Use all of the game pieces from the main game with the exception of the maps and territory cards. The Asteroid Colonies expansion makes a great supplement to this board since there are no moons.

### Nuclear Cards

Acquire a 10-sided die for use with the Mother; use a 6-sided die for Aqua Brother. Use the point charts on the board in place of the charts on the card.
